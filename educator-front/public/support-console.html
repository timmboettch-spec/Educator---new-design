One login for Sales and Support.

This console covers Access Keys — the seats and hardware set up on a district's account — only. District sign-ups, sales pipeline, and billing all live in NetSuite — once a deal is ready, Support's job here is simply to issue the right keys.

  • Set up Access Keys on a district's account, granting Access Keys — AI seats for online, pooled simulations and Hardware Keys for online, device-based simulations on hardware devices (Chromebooks/laptops/tablets) — together, in a single action
  • AI seats are one pooled quantity the District Admin can split across their schools; each Hardware Key maps to exactly one hardware device — a Chromebook, laptop, or tablet, not the physical manikin/task trainer, which has no software connection of its own — installed before it ships so it works on arrival, and still emailed to the district to associate for tracking. Every hardware-keyed device needs internet — at install, at pre-shipment test, and at every session
  • A brand-new district's first order gets a fresh account setup; an existing account needing more is topped up directly by Support, with no new code issued
  • Replace a wrongly-consumed seat, or replace a damaged Hardware Key — unused-seat returns now flow through the district's Educator Portal

Report Damaged / Replace Key

This device's Hardware Key is being retired — a new physical device and key will be shipped.

This marks the old key as Replaced and automatically generates a new Hardware Key for the replacement device, linked to the same account — keeping its remaining hours allowance and the same expiration date rather than resetting the clock. Mark the new key Shipped once the device goes out, which is where its own Device Serial Number gets captured.

Renew Hardware Key Hours

Grant extra hours on top of the normal allowance — for a device that's paused, or a district that needs more before the allowance grows on its own.

This is separate from the key's calendar Expiry date (edited above) — whichever limit is reached first still applies. Granted hours are added immediately and are logged below for reference; if the key was paused, it becomes usable again right away.
